# 运营 Listing 上架草稿 Skill

## 适用场景

运营需要根据 SKU、产品名称、核心卖点、目标站点、受众、竞品差异和合规限制生成完整 Amazon Listing 上架草稿。

典型触发：

- 生成 Listing 并保存草稿。
- 生成标题、五点描述、关键词、促销文案并写入平台草稿区。
- 聊天中明确出现 Listing、上架、保存草稿、上传草稿、标题、五点、关键词等执行型表达。

## 不适用场景

- 用户只是询问 Listing 规则或平台政策，应优先走 RAG。
- 用户要求直接发布到 Amazon，不在本 Skill 第一阶段范围内。
- 客服或财务岗位请求生成运营 Listing，应由权限闸门拒绝。

## 权限规则

- 仅运营岗位或管理员可执行。
- 非管理员必须启用 `automation-listing`。
- 管理员执行时必须按运营岗位收窄执行上下文。
- 只保存平台草稿，不直接发布到外部平台。

## 执行步骤

1. 校验岗位和 AI 应用启用状态。
2. 使用现有 `run_ai_workflow("operations_listing_launch")` 生成 Listing 内容。
3. 写入 `platform_drafts`，状态等待运营审核。
4. 提交外部写回任务时只进入草稿或待执行状态，不伪装已发布。
5. 写入运行记录、步骤和审计。

## 输出格式

- Listing 标题。
- 五点描述。
- 产品描述。
- 后台搜索词。
- 促销文案。
- 中文优化备注。
- 平台草稿 ID、草稿状态、写回状态和运行记录 ID。

## 安全边界

ReAct 可以选择本 Skill，但不能直接执行。真正执行必须先经过 Skill Executor 的岗位、AI 应用、ERP 资源、运行记录和审计校验。
