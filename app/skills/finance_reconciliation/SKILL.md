# 财务对账自动化 Skill

## 适用场景

财务上传 Amazon 结算表、物流账单、采购成本表、广告费表和汇率表，系统按订单号/SKU 匹配并生成订单利润表和异常账单。

典型触发：

- 上传多份对账 Excel，生成利润表。
- 匹配结算、物流、采购和广告费用。
- 标记负利润、缺成本、缺物流费、缺汇率和未匹配费用。

## 不适用场景

- 没有真实文件内容时不能执行。
- 非财务岗位不能调用。
- 不能自动入账、付款或改写 ERP。

## 权限规则

- 仅财务岗位或管理员可执行。
- 非管理员必须启用 `finance-reconciliation`。
- 文件限制：最多 8 个文件，单个最大 8MB，总大小最大 32MB。
- 结果必须由财务人工复核。

## 执行步骤

1. 校验岗位、AI 应用启用状态、文件数量、单文件大小和总大小。
2. 使用 pandas 读取真实 Excel workbook。
3. 识别订单号、SKU、金额、费用、汇率等字段。
4. 按订单号/SKU 匹配结算、物流、采购、广告和汇率。
5. 校验汇率表：外币缺汇率、非正数/非有限汇率、同币种汇率冲突时要求补充或按期间拆分，不默认使用 1 折算。基础币种汇率固定为 1。
6. 计算净收入及已提供费用。未匹配到正数采购成本或物流费的行标记待补资料，总成本、利润和利润率留空；存在此类行时整体利润合计留空，可计算行单独汇总。零成本豁免规则尚未配置，零值也需复核。
7. 使用 `reconcile_finance_workbooks(...)` 生成对账 Excel。
8. 保存文件产物并写入运行记录、步骤和审计。

## 输出格式

- 对账 Excel 文件。
- 对账摘要。
- 订单利润表。
- 异常账单。
- 字段识别结果。
- 源文件概览。
- 运行记录 ID。
- 数据完整性、可计算行数、待补资料行数、财务复核状态；不完整批次不提供整体利润合计。

## 安全边界

该 Skill 只生成复核文件，不自动入账、不自动付款、不自动修改 ERP。大模型不能决定财务数字，核心计算必须由后端确定性规则完成。

没有币种列的文件沿用用户指定基础币种；币种列中存在空值则要求补充，不能将混币文件的缺项默认为基础币种。

当前输出是订单贡献利润复核表，仅包含已提供的费用，并非结算批次与银行到账核对。未提供的广告费、税费等不纳入计算；不能据此宣称完整净利润或已对平。混期间汇率必须由财务拆分，当前不自动选择期间或税率。
